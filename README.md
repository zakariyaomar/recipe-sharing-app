# recipe-sharing-app

A simple recipe-sharing app for Kenyan dishes. The seed data now includes photo URLs for each recipe so the app can display food images alongside titles, descriptions, and ingredients.

## Features

- Recipe CRUD API with Prisma and PostgreSQL
- Recipe photo support via `imageUrl`
- Seeded sample recipes inspired by Kenyan cuisine

To regenerate the seeded recipes with their photos, run:

```bash
npm run seed
```
